# 🥐 Skits

**Skits** — short for biscuits — is a cozy bakery site built to bring delicious flavors from our kitchen to your home.  
Freshly baked, always from scratch.

---

## 🚀 Project Overview

- Browse and buy homemade biscuits online
- Discover creative recipes you can try at home
- Checkout securely with Stripe
- Manage users and orders with MongoDB

---

## 🛠 Tech Stack

- **Next.js** — Frontend and Backend Framework
- **Stripe** — Payment Processing
- **MongoDB** — Database for Users and Orders
- **TailwindCSS** — Styling and Layout
